# Los Abuelos

Proyecto web construido con [Astro](https://astro.build).

## Estructura del proyecto

```text
/
├── public/
├── src
│   ├── assets
│   ├── components
│   ├── layouts
│   └── pages
└── package.json
```

## Comandos

Todos los comandos se ejecutan desde la raíz del proyecto:

| Comando              | Acción                                                |
| :-------------------- | :----------------------------------------------------- |
| `npm install`          | Instala las dependencias                               |
| `npm run dev`           | Inicia el servidor local en `localhost:4321`           |
| `npm run build`         | Genera la build de producción en `./dist/`             |
| `npm run preview`       | Previsualiza la build localmente antes de desplegar    |
| `npm run astro ...`     | Ejecuta comandos del CLI de Astro (`astro add`, etc.)  |

## Documentación

Más información en la [documentación de Astro](https://docs.astro.build).
